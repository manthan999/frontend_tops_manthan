7. Common Bugs & Fixes

Bug Problem Fix
Double Add Same product added repeatedly Check product ID before push()
Wrong Cart Count Count increases for duplicate products Update count only after successful push()
Empty Form Form submits blank values Use trim() and conditional validation
Empty Review Blank review gets submitted Check review before submit
Duplicate Follow Same user appears multiple times Use includes() before push()
Invalid Rating Rating outside valid range Validate rating between 1 and 5
