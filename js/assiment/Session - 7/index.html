Event Flow

Event flow describes how an event travels through the DOM. It generally has three phases: capturing → target → bubbling.

In event bubbling, an event triggered on a child element can move upward to its parent elements. For example, clicking an "Add to Cart" button inside a product card may also trigger a click handler attached to the product card.
